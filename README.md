# flutter-readiness-tracker

Flutter Readiness Tracker — A modern, fully responsive Flutter Web/mobile application built for evaluating developer readiness.

## ✨ Features

- **🔐 Secure Authentication:** Implements salted SHA-256 password hashing and rigorous client-side validation.
- **📋 Interactive Skills Checklist:** Track core competencies (Flutter, Dart, REST APIs, State Management, etc.) dynamically.
- **🧠 Developer Quiz:** An engaging 8-question technical assessment to test fundamental concepts.
- **🎯 Resume Keyword Matcher:** Evaluates profile strength against modern industry standards and ATS requirements.
- **🌐 REST API Integration:** Real-time task fetching with robust loading, error handling, and retry states.
- **💾 Local Persistence:** Data management handled seamlessly via `SharedPreferences` and `Provider` state management.

## 🛠️ Tech Stack

- **Framework:** Flutter (Web / Mobile)
- **Language:** Dart
- **State Management:** Provider
- **Storage:** SharedPreferences
- **CI/CD:** GitHub Actions (Automated Deployment to GitHub Pages)
